Manual de Experto: Cuota LGD 2%

Sistema Integrado de Análisis de Plantillas (Criterio Técnico 98/2016)

Requisito Previo a la Herramienta Web
Antes de subir los datos al Dashboard web, es *crítico* sanear el bruto exportado por SAP. SAP genera solapamientos en las fechas de los contratos cuando hay cambios de categoría que inflan la plantilla. Este manual incluye la Macro VBA indispensable para limpiar esos datos.

FASE 1: Preparación (Macro VBA de Limpieza)

El código a continuación arregla el problema de los contratos solapados en SAP y calcula los Días equivalentes hacia atrás de forma milimetrada.

Cómo instalar el motor

  1. Crea un libro Excel "Herramienta_Calculo.xlsm".
  2. Pega los datos extraídos de SAP en una pestaña llamada Datos.
  3. Asegúrate de tener Fecha Ficticia de Inicio en R1 y Fecha Ficticia Fin en S1.
  4. Pega esta Macro V8.1 en un módulo.
Sub LGD_Splitter_v8()
    Dim wsMaster As Worksheet
    Dim lastRow As Long
    Dim i As Long
    Dim StartPeriod As Date
    Dim EndPeriod As Date
    Dim cccCol As Long, pernrCol As Long, startCol As Long, endCol As Long
    Dim grpCol As Long, daysCol As Long, udCol As Long
    
    ' [1] CONFIGURACIÓN INICIAL
    Set wsMaster = ThisWorkbook.Sheets("Datos")
    lastRow = wsMaster.Cells(wsMaster.Rows.Count, "A").End(xlUp).Row
    
    ' Leer fechas fiscales de R1 y S1 (Cambiarlas a las de tu mes)
    StartPeriod = wsMaster.Cells(1, "R").Value
    EndPeriod = wsMaster.Cells(1, "S").Value
    
    ' Mapeo de columnas (Ajustar si tu SAP es distinto)
    pernrCol = 6   ' F: Nº pers.
    startCol = 10  ' J: FeIniContr
    endCol = 11    ' K: Baja Real
    cccCol = 22    ' V: Soc.
    grpCol = 15    ' O: Nueva columna Grupo
    daysCol = 14   ' N: Nueva columna Días
    udCol = 16     ' P: Nueva columna Unidades
    
    ' Títulos de las nuevas columnas
    wsMaster.Cells(1, daysCol).Value = "Días"
    wsMaster.Cells(1, grpCol).Value = "Grupo LGD"
    wsMaster.Cells(1, udCol).Value = "Unidades"
    
    ' --------- CORE LOGIC V8.1: DICTIONARY BACKTRACKING ------------
    ' Esta es la magia para evitar los solapamientos de SAP.
    Dim dictBajas As Object
    Set dictBajas = CreateObject("Scripting.Dictionary")
    Dim currentPernr As String
    Dim nextStartDate As Date
    Dim effEnd As Date
    Dim effStart As Date
    
    ' Leemos de Abajo hacia Arriba para heredar los "Dado de baja" reales
    For i = lastRow To 2 Step -1
        currentPernr = wsMaster.Cells(i, pernrCol).Text
        
        ' Si la celda dice "Dado de baja", guardamos esa fecha como límite para este empleado
        Dim statusTxt As String
        statusTxt = wsMaster.Cells(i, 13).Text ' M: Texto medida
        
        If InStr(1, UCase(statusTxt), "DADO DE BAJA") > 0 Or InStr(1, UCase(statusTxt), "BAJA") > 0 Then
            Dim bajaDate As Date
            bajaDate = wsMaster.Cells(i, endCol).Value
            dictBajas(currentPernr) = bajaDate
            
            ' Como es registro puro de baja, no suma días en ese tramo
            wsMaster.Cells(i, daysCol).Value = 0
            
        Else
            ' Es un registro Activo. Calculamos su longitud real
            If Not dictBajas.Exists(currentPernr) Then
                effEnd = DateSerial(9999, 12, 31)
            Else
                effEnd = dictBajas(currentPernr)
            End If
            
            effStart = wsMaster.Cells(i, startCol).Value
            
            ' Recorte Fiscal
            If effStart < StartPeriod Then effStart = StartPeriod
            If effEnd > EndPeriod Then effEnd = EndPeriod
            
            ' Cálculo de los días efectivos (Inclusivos)
            Dim validDays As Long
            validDays = DateDiff("d", effStart, effEnd) + 1
            If validDays < 0 Then validDays = 0
            
            ' Anotar fijamente en Columnas N
            wsMaster.Cells(i, daysCol).Value = validDays
            
            ' ---------- CLASIFICACIÓN TÉCNICA A/B ----------
            Dim contratoType As String
            contratoType = wsMaster.Cells(i, 17).Text ' Q: Clase Contr.
            
            Dim isGroupA As Boolean
            isGroupA = False
            
            ' Fijos / Indefinidos: A
            If InStr(1, UCase(contratoType), "100") > 0 Or InStr(1, UCase(contratoType), "200") > 0 Or InStr(1, UCase(contratoType), "300") > 0 Then
                isGroupA = True
            End If
            
            ' Análisis Días Brutos (Start Real vs End Real sin cortar por Fiscal)
            Dim bruteDays As Long
            bruteDays = DateDiff("d", wsMaster.Cells(i, startCol).Value, effEnd) + 1
            If bruteDays > 365 Then isGroupA = True ' El Temporal se volvió largo
            
            If isGroupA Then
                wsMaster.Cells(i, grpCol).Value = "Grupo A"
                ' Criterio 98/2016: Promedio A = Días / 365
                wsMaster.Cells(i, udCol).Value = Round(validDays / 365, 2)
            Else
                wsMaster.Cells(i, grpCol).Value = "Grupo B"
                ' Criterio 98/2016: B = Sumatoria Días en el año (luego la web lo divide por 200 y redondea)
                wsMaster.Cells(i, udCol).Value = validDays
            End If
            
            ' ¡ESTA ES LA REPARACIÓN LÓGICA V8.1!
            ' Pisamos la memoria para que la fila de arriba (contrato anterior) no pueda sobrepasar el día anterior a esto
            dictBajas(currentPernr) = effStart - 1
            
        End If
    Next i
    
    MsgBox "Lógica V8.1 Procesada: Base Limpia y Estática.", vbInformation
End Sub

FASE 2: El Dashboard Web

Una vez que el archivo ha limpiado el Excel con la Macro, puedes arrastrar la pestaña 'TOTAL' (La que unifica todo) a la Herramienta Web.

  • Simulación Instantánea: La web leerá los Grupos A y B estáticos. El Grupo B se divide entre 200 (redondeando siempre hacia arriba) calculando la cuota final del 2% real.
  • Filtro por Excel: Puedes usar el desplegable para ir rotando por los CCC o por el "Reporte Global" sin tener que salir ni hacer varias Macros.
  • Medidas Alternativas: Puedes tildar la píldora para justificar excepciones y el Dashboard se autocoloreará de Éxito en la Exportación PDF.
Misión cumplida. La herramienta no dependerá jamás de arrastrar fórmulas en Excel que puedan romperse con un mal click, su integridad ahora es matemática pura precalculada y unificada.
