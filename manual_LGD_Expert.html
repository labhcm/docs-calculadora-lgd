Sistema Global LGD 2% - Manual del Proyecto

Este documento es la guía oficial para entender y operar el ecosistema de validación de la Cuota de Reserva del 2% de trabajadores con discapacidad. Está diseñado para que cualquier analista, sin importar su experiencia previa, pueda procesar los datos masivos de SAP y obtener los KPIs legales de auditoría.

🎯 1. Objetivo de la Herramienta y Criterio Técnico

El sistema automatiza el cálculo de plantilla basándose estrictamente en el Criterio Técnico 98/2016 de la Inspección de Trabajo.

Resumen Legal del Criterio "Días Vivos":
• Grupo A (Clásicos): Contratos indefinidos, o temporales cuyo computo anual real sea superior a 365 días. El sistema recoge todos sus días de alta en el periodo analizado y los divide entre 365. Quien trabaja todo el año suma 1 entero.
• Grupo B (Temporales Cortos): Contratos temporales cuyo computo real sea menor a un año. Se suman todos los días que los integrantes de este grupo estuvieron de alta y su total se divide entre 200. (Se redondea siempre al entero superior, pero sin sobrepasar nunca el número físico real de personas que conformaron este grupo).
• La suma del Grupo A y el Grupo B conforma la Plantilla Total. El 2% de esta cifra dicta la obligatoriedad.

💻 2. Herramienta Principal: La Calculadora Web (Dashboard)

La vía principal, más rápida y oficial para sacar los informes de la LGD es la herramienta web Calculadora_LGD_Standalone.html. Es una aplicación local robusta que procesa archivos de Excel masivos en tu propio navegador (sin enviar datos a internet por GDPR).

Paso 1: Archivo Base de SAP

Necesitas tener el bruto de SAP descargado en Excel (xlsx o csv). El sistema buscará inteligentemente las cabeceras independientemente de cómo se llame el informe, siempre que contenga las siguientes métricas o alias aproximados:

  • Nº Personal: Para identificar al trabajador en tramos fragmentados.
  • Empresa/Sociedad: Para dividir a los trabajadores.
  • CCC (Cuenta de Cotización): Opcional, pero necesario para agrupar en el desglose mensual.
  • Fecha Inicio y Fecha de Baja: Para los solapes cronológicos.
  • Identificación/Tipo de Contrato: Para saber si buscar en Grupo A o B.

Paso 2: Modo de Uso

  1. Abre el archivo Calculadora_LGD_Standalone.html con Chrome / Edge / Firefox.
  2. Fichero 1 (Opcional): Si tienes un informe específico del Personal con Discapacidad de la empresa en un Excel separado, arrástralo a la caja delineada asignada. Esto precargará a los discapacitados en memoria para cruzar datos.
  3. Fichero 2 (Maestro Principal): Arrastra tu informe global de SAP en la zona de subida principal (azul).
  4. Configuración: Selecciona el periodo a analizar (ej. 01/03/2025 al 28/02/2026).
  5. Pulsa "Procesar Datos".

Paso 3: Análisis y Reporte de Pantalla

La aplicación cuenta con un sofisticado Motor Cronológico JavaScript. Este motor:

  • Detecta cambios de formato en el Excel automáticamente.
  • Resuelve periodos superpuestos de un mismo trabajador para evitar que "doblen días" si tienen altas paralelas por error administrativo.
  • Filtra las "Fechas de Mentira" técnicas de SAP (ej. 31/12/2999).
  • Rastrea el nombre del tipo de contrato para esquivar los fallos de codificación de SAP (pérdida de acentos).

Presentará entonces un Resumen Multi-Sociedad. Podrás acceder a los detalles individuales, ver la curva mensual, consultar la tabla exacta de trabajadores aportados al Grupo B y exportar los resultados a PDF con un solo clic limpio.

⚙️ 3. Herramienta de Respaldo: Macro VBA LGD_Splitter (Modo Experto)

Como mecanismo secundario, y a su vez motor de depuración, se mantiene disponible la famosa Macro de VBA v9.1. Esta herramienta incrustada en Excel hace matemáticamente los mismos cálculos que la calculadora Web, pero deja los resultados escritos físicamente fila a fila para ser auditados e inspeccionados manualmente.

[!WARNING] Importante
El flujo de fórmulas explícitas de Excel (BUSCARV, SI.CONJUNTO) integrado en las celdas se ha retirado definitivamente. La complejidad de resolver tramos de altas y bajas cruzadas entre DNI's múltiples exigía una carga lógica que colgaba los procesadores. La Macro VBA y el Dashboard Web son las únicas fuentes de verdad aceptadas.

Instrucciones de la Macro VBA v9.1

  1. Mantén el volcado maestro de SAP en la primera hoja de tu Excel (Datos desde la Columna A a la M como mínimo).
  2. Introduce la Fecha de Inicio legal en la celda R1.
  3. Introduce la Fecha de Fin legal en la celda S1.
  4. Al ejecutar la macro mostrada a continuación se creará una "Fase Cronológica". Analizará y podará los solapes, escribirá los días activos en la columna N, categorizará el Grupo (A o B) en la columna O y dejará la matemática aportada en la columna P. Acto seguido, generará una pestaña nueva de Excel limpia e independiente para cada una de las sociedades encontradas.

Código Fuente Total a inyectar en Módulo VBA:

Sub DividirSociedades_LGD_v9_1()
    Dim wsOrigen As Worksheet, wsNueva As Worksheet
    Dim UltimaFila As Long, i As Long
    Dim Diccionario As Object
    Dim CodigoSoc As String, NombreHoja As String
    Dim RangoA_S As Range

    Dim FInicio As Date, FRefInicio As Date, FRefFin As Date
    Dim Dias As Long, j As Long, k As Long
    Dim key As Variant

    Set wsOrigen = ActiveSheet

    ' --- VALIDACIÓN FECHAS R1 / S1 ---
    If Not IsDate(wsOrigen.Range("R1").Value) Or Not IsDate(wsOrigen.Range("S1").Value) Then
        MsgBox "Faltan las fechas de inicio/fin en R1 y S1", vbCritical
        Exit Sub
    End If

    FRefInicio = wsOrigen.Range("R1").Value
    FRefFin    = wsOrigen.Range("S1").Value

    wsOrigen.AutoFilterMode = False
    wsOrigen.Range("A:A").NumberFormat = "@"
    UltimaFila = wsOrigen.Cells(wsOrigen.Rows.Count, "A").End(xlUp).Row
    Application.ScreenUpdating = False
    Application.DisplayAlerts  = False

    ' FASE A: CÁLCULO DE DÍAS Y GRUPOS (Motor Cronológico LGD v9.1)
    Dim DictPerson As Object
    Set DictPerson = CreateObject("Scripting.Dictionary")
    
    Dim NpersD As String
    For i = 2 To UltimaFila
        NpersD = CStr(wsOrigen.Cells(i, 4).Value)
        If NpersD <> "" Then
            If Not DictPerson.Exists(NpersD) Then DictPerson.Add NpersD, New Collection
            DictPerson(NpersD).Add i
        End If
    Next i

    Dim colRows As Collection, arrRows() As Long, actualEnds() As Date

    For Each key In DictPerson.Keys
        Set colRows = DictPerson(key)
        ReDim arrRows(1 To colRows.Count)
        ReDim actualEnds(1 To colRows.Count)
        
        For j = 1 To colRows.Count
            arrRows(j) = colRows(j)
        Next j

        ' 1. Capturar Fecha de Baja Real
        For j = 1 To UBound(arrRows)
            Dim rowIdx As Long
            rowIdx = arrRows(j)
            Dim Status As String
            Status = UCase(Trim(wsOrigen.Cells(rowIdx, 13).Value)) ' col M
            
            Dim BajaReal As Date
            If Status = "DADO DE BAJA" Or Status = "INACTIVO" Then
                Dim BajaRaw As Variant: BajaRaw = wsOrigen.Cells(rowIdx, 9).Value2
                If IsDate(wsOrigen.Cells(rowIdx, 9).Value) And IsNumeric(BajaRaw) And BajaRaw > 0 And BajaRaw < 2958465 Then
                    BajaReal = wsOrigen.Cells(rowIdx, 9).Value
                Else
                    BajaReal = DateSerial(9999, 12, 31)
                End If
            Else
                BajaReal = DateSerial(9999, 12, 31)
            End If
            actualEnds(j) = BajaReal
        Next j

        ' 2. Orden Cronológico
        Dim tempRow As Long, tempDate As Date, startJ As Date, startK As Date
        For j = 1 To UBound(arrRows) - 1
            For k = j + 1 To UBound(arrRows)
                startJ = wsOrigen.Cells(arrRows(j), 7).Value
                startK = wsOrigen.Cells(arrRows(k), 7).Value
                
                Dim swap As Boolean: swap = False
                If startJ > startK Then swap = True ElseIf startJ = startK Then If actualEnds(j) < actualEnds(k) Then swap = True
                
                If swap Then
                    tempRow = arrRows(j): arrRows(j) = arrRows(k): arrRows(k) = tempRow
                    tempDate = actualEnds(j): actualEnds(j) = actualEnds(k): actualEnds(k) = tempDate
                End If
            Next k
        Next j

        ' 3. Resolutor de Solapamientos
        If UBound(arrRows) > 1 Then
            Dim activeHorizon As Date: activeHorizon = actualEnds(1)
            For j = 1 To UBound(arrRows) - 1
                Dim currentStart As Date, nextStart As Date
                currentStart = wsOrigen.Cells(arrRows(j), 7).Value: nextStart = wsOrigen.Cells(arrRows(j + 1), 7).Value

                If currentStart = nextStart Then
                    actualEnds(j + 1) = currentStart - 1
                Else
                    If nextStart <= activeHorizon Then
                        Dim dayBeforeNext As Date: dayBeforeNext = nextStart - 1
                        If actualEnds(j) > dayBeforeNext Then actualEnds(j) = dayBeforeNext
                        If actualEnds(j + 1) > activeHorizon Then activeHorizon = actualEnds(j + 1)
                    Else
                        If actualEnds(j + 1) > activeHorizon Then activeHorizon = actualEnds(j + 1)
                    End If
                End If
            Next j
        End If

        ' 4. Escribir Resultados Días / Grupo
        For j = 1 To UBound(arrRows)
            Dim rIdx As Long: rIdx = arrRows(j)
            Dim InicioAjustado As Date, FinAjustado As Date
            InicioAjustado = wsOrigen.Cells(rIdx, 7).Value: FinAjustado = actualEnds(j)
            
            If InicioAjustado < FRefInicio Then InicioAjustado = FRefInicio
            If FinAjustado > FRefFin Then FinAjustado = FRefFin
            If FinAjustado >= InicioAjustado Then Dias = DateDiff("d", InicioAjustado, FinAjustado) + 1 Else Dias = 0
            
            wsOrigen.Cells(rIdx, 14).Value = Dias
            If Dias > 0 Then
                Const H_SENTINEL As Long = 365000
                Dim TipoContrato As String: TipoContrato = Trim(wsOrigen.Cells(rIdx, 12).Value) ' col L
                
                Dim EsTemporal As Boolean
                EsTemporal = ((InStr(1, TipoContrato, "Dur.temp", vbTextCompare) > 0 Or _
                              InStr(1, TipoContrato, "Duración", vbTextCompare) > 0 Or _
                              InStr(1, TipoContrato, "Temporal", vbTextCompare) > 0) And _
                              InStr(1, TipoContrato, "transformacion", vbTextCompare) = 0 And _
                              InStr(1, TipoContrato, "transformación", vbTextCompare) = 0)
                
                Dim FechaHraw As Variant: FechaHraw = wsOrigen.Cells(rIdx, 8).Value2 ' col H numérico
                Dim EsGrupoA As Boolean
                If EsTemporal Then
                    If IsNumeric(FechaHraw) And FechaHraw > 0 And FechaHraw < H_SENTINEL Then
                        EsGrupoA = (DateDiff("d", wsOrigen.Cells(rIdx, 7).Value, CDate(wsOrigen.Cells(rIdx, 8).Value)) > 365)
                    Else
                        EsGrupoA = (DateDiff("d", wsOrigen.Cells(rIdx, 7).Value, FRefFin) > 365)
                    End If
                Else
                    If IsEmpty(wsOrigen.Cells(rIdx, 8).Value) Or FechaHraw = 0 Or FechaHraw = "" Then
                        EsGrupoA = True
                    ElseIf IsDate(wsOrigen.Cells(rIdx, 8).Value) Then
                        EsGrupoA = (DateDiff("d", wsOrigen.Cells(rIdx, 7).Value, CDate(wsOrigen.Cells(rIdx, 8).Value)) > 365)
                    Else
                        EsGrupoA = True
                    End If
                End If

                If EsGrupoA Then
                    wsOrigen.Cells(rIdx, 15).Value = "Grupo A"
                    wsOrigen.Cells(rIdx, 16).Value = Round(Dias / 365, 3)
                Else
                    wsOrigen.Cells(rIdx, 15).Value = "Grupo B"
                    wsOrigen.Cells(rIdx, 16).Value = Dias
                End If
            Else
                wsOrigen.Cells(rIdx, 15).Value = "Grupo B": wsOrigen.Cells(rIdx, 16).Value = 0
            End If
        Next j
    Next key

    ' FASE B: GENERACIÓN DE PESTAÑAS
    Set RangoA_S = wsOrigen.Range("A1:S" & UltimaFila)
    Set Diccionario = CreateObject("Scripting.Dictionary")

    For i = 2 To UltimaFila
        CodigoSoc = Trim(wsOrigen.Cells(i, 1).Text)
        If CodigoSoc <> "" And Not Diccionario.Exists(CodigoSoc) Then
            Diccionario.Add CodigoSoc, 1
            NombreHoja = Left(Replace(Replace(CodigoSoc, "/", "_"), "*", ""), 31)
            On Error Resume Next
            Sheets(NombreHoja).Delete
            On Error GoTo 0
            Set wsNueva = Sheets.Add(After:=Sheets(Sheets.Count))
            wsNueva.Name = NombreHoja
            wsOrigen.AutoFilterMode = False
            RangoA_S.AutoFilter Field:=1, Criteria1:=CodigoSoc
            RangoA_S.SpecialCells(xlCellTypeVisible).Copy Destination:=wsNueva.Range("A1")
            wsNueva.Columns.AutoFit
        End If
    Next i
    wsOrigen.AutoFilterMode = False

    ' FASE C: ORDENAR HOJAS NUMÉRICAMENTE
    Dim hojas() As Variant, idxL As Long, tempVar As Variant
    ReDim hojas(1 To Diccionario.Count)
    idxL = 1

    For Each key In Diccionario.Keys
        If IsNumeric(key) Then
            hojas(idxL) = CDbl(key)
            idxL = idxL + 1
        End If
    Next key

    For j = LBound(hojas) To UBound(hojas) - 1
        For k = j + 1 To UBound(hojas)
            If hojas(j) > hojas(k) Then tempVar = hojas(j): hojas(j) = hojas(k): hojas(k) = tempVar
        Next k
    Next j

    For j = LBound(hojas) To UBound(hojas)
        If hojas(j) <> 0 Then
            On Error Resume Next
            Sheets(CStr(hojas(j))).Move After:=wsOrigen
            Set wsOrigen = Sheets(CStr(hojas(j)))
            On Error GoTo 0
        End If
    Next j

    Sheets(1).Activate
    Application.ScreenUpdating = True
    Application.DisplayAlerts  = True

    MsgBox "LGD v9.1 completado." & vbCrLf & "Sociedades generadas: " & Diccionario.Count, vbInformation

End Sub
