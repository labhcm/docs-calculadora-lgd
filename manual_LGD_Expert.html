Este documento resume las funcionalidades, mejoras implementadas y sirve como guía paso a paso para cualquier usuario que necesite entender cómo operar el ecosistema completo desde cero: desde la extracción de datos en SAP mediante Excel/VBA hasta la visualización final en el Dashboard web.

🎯 1. Objetivo de la Herramienta

El ecosistema está diseñado para automatizar el cálculo del cumplimiento de la Cuota de Reserva del 2% de trabajadores con discapacidad, basándose estrictamente en el Criterio Técnico 98/2016 de la Inspección de Trabajo.

Se divide en dos grandes fases:

  1. Preparación de Datos (Excel/VBA): Extracción, limpieza y segregación masiva de sociedades desde el volcado bruto de SAP.
  2. Dashboard Visual (Web): Ingestión del volcado finalizado y despliegue del panel de resultados, desglose mensual y validación legal con interacción en tiempo real.

🛠️ 2. Fase 1: Preparación Básica (SAP a Excel)

[!NOTE] Notas de la Versión Definitiva: LGD Expert v9.0 (Motor Completo)
[CRITICAL FIX] Días Duplicados y Tramos Complejos: El sistema ahora calcula con precisión los días libres de solapamiento analizando el histórico de altas y bajas por empleado (Nº personal en lugar de NIF para evitar colisiones). Clasifica automáticamente en "Grupo A" (contratos de >365 días o indefinidos) o "Grupo B" (resto), e ignora correctamente las fechas centinelas (ej. 31/12/9999).

2.1 Preparación de la Hoja Maestra

  1. Asegúrate de que tus datos de SAP extraídos ocupan de la columna A a la S.
  2. Fechas de Referencia: Coloca en R1 el inicio del periodo (ej: 01/03/2025) y en S1 el fin (ej: 28/02/2026).

2.2 Opción A: Fórmulas de Excel (Cálculo Manual)

Si necesitas depurar los cálculos en el propio Excel sin usar la macro de VBA, el motor está replicado mediante las siguientes fórmulas a incluir en columnas libres (asumiendo datos en la fila 2):

  • 1. Baja Efectiva (Ignorar solapamientos y fechas 9999):
    =MIN.SI.CONJUNTO($I:$I; $D:$D; $D2; $I:$I; ">="&$G2; $I:$I; "<"&2958465; $I:$I; ">0")
    (Devuelve la baja real buscando el Nº de personal en la columna D y omitiendo altas futuras y la fecha técnica 31.12.9999 de SAP - valor serial 2958465).
  • 2. Días vivos en el Periodo (Columna N):
    =SI(ESPACIOS($M2)="DADO DE BAJA"; 0; MAX(0; MIN([Celda BajaEfectiva]; $S$1) - MAX($G2; $R$1) + 1))
  • 3. Clasificación de Grupo (Columna O):
    Contratos indefinidos o temporales que duren más de 365 días (teniendo en cuenta col L para determinar tipo de contrato) pasan a Grupo A. El resto es Grupo B.
  • 4. Factor Computable Final (Columna P):
    =SI(O2="Grupo A"; N2/365; N2)

2.3 Opción B: Ejecución Automática (Macro LGD_Splitter_v9)

Esta macro es la vía oficial y agrupa todos los cálculos matemáticos prescindiendo de colgar tu Excel con miles de fórmulas complejas. Aplica la lógica exacta de la Ley y, finalmente, divide la matriz originando tantas pestañas separadas como Sociedades tengas:

Sub DividirSociedades_LGD_v9()

    Dim wsOrigen As Worksheet, wsNueva As Worksheet
    Dim UltimaFila As Long, i As Long
    Dim Diccionario As Object
    Dim CodigoSoc As String, NombreHoja As String
    Dim RangoA_S As Range

    Dim FInicio As Date, FRefInicio As Date, FRefFin As Date
    Dim Dias As Long

    Set wsOrigen = ActiveSheet

    ' --- VALIDACIÓN FECHAS R1 / S1 ---
    If Not IsDate(wsOrigen.Range("R1").Value) Or Not IsDate(wsOrigen.Range("S1").Value) Then
        MsgBox "Faltan las fechas de inicio/fin en R1 y S1", vbCritical
        Exit Sub
    End If

    FRefInicio = wsOrigen.Range("R1").Value
    FRefFin    = wsOrigen.Range("S1").Value

    wsOrigen.AutoFilterMode = False
    wsOrigen.Range("A:A").NumberFormat = "@"

    UltimaFila = wsOrigen.Cells(wsOrigen.Rows.Count, "A").End(xlUp).Row

    Application.ScreenUpdating = False
    Application.DisplayAlerts  = False

    ' ═══════════════════════════════════════════════════════
    ' FASE A: CÁLCULO DE DÍAS Y GRUPOS
    '   Clave: Nº pers. (col D) — no NIF (col F)
    ' ═══════════════════════════════════════════════════════

    Dim DictBajas As Object
    Set DictBajas = CreateObject("Scripting.Dictionary")

    For i = UltimaFila To 2 Step -1

        ' Clave = Nº pers. (col D)
        Dim NpersD As String
        NpersD = CStr(wsOrigen.Cells(i, 4).Value)

        Dim Status As String
        Status = Trim(wsOrigen.Cells(i, 13).Value)   ' col M

        ' ── EMPLEADO DADO DE BAJA ──
        If UCase(Status) = "DADO DE BAJA" Or UCase(Status) = "INACTIVO" Then

            ' Ignorar fecha sentinel 31/12/9999 (serial 2958465)
            Dim BajaRaw As Variant
            BajaRaw = wsOrigen.Cells(i, 9).Value2

            If IsDate(wsOrigen.Cells(i, 9).Value) _
               And IsNumeric(BajaRaw) _
               And BajaRaw > 0 _
               And BajaRaw < 2958465 Then
                DictBajas(NpersD) = wsOrigen.Cells(i, 9).Value
            End If

            wsOrigen.Cells(i, 14).Value = 0           ' N = 0
            wsOrigen.Cells(i, 15).Value = "Grupo B"   ' O
            wsOrigen.Cells(i, 16).Value = 0           ' P = 0

        ' ── EMPLEADO ACTIVO ──
        ElseIf UCase(Status) = "ACTIVO" Then

            If IsDate(wsOrigen.Cells(i, 7).Value) Then   ' col G

                FInicio = wsOrigen.Cells(i, 7).Value

                ' Fecha de baja efectiva para este Nº pers.
                Dim BajaReal As Date
                If DictBajas.Exists(NpersD) Then
                    BajaReal = DictBajas(NpersD)
                    If BajaReal < FInicio Then BajaReal = DateSerial(9999, 12, 31)
                Else
                    BajaReal = DateSerial(9999, 12, 31)
                End If

                ' Recorte al periodo de referencia
                Dim InicioAjustado As Date, FinAjustado As Date
                InicioAjustado = FInicio
                If InicioAjustado < FRefInicio Then InicioAjustado = FRefInicio

                FinAjustado = BajaReal
                If FinAjustado > FRefFin Then FinAjustado = FRefFin

                ' Columna N — días activos en el periodo
                If FinAjustado >= InicioAjustado Then
                    Dias = DateDiff("d", InicioAjustado, FinAjustado) + 1
                Else
                    Dias = 0
                End If
                wsOrigen.Cells(i, 14).Value = Dias

                ' ── Columna O — Grupo ──
                Const H_SENTINEL As Long = 365000

                Dim TipoContrato As String
                TipoContrato = Trim(wsOrigen.Cells(i, 12).Value)  ' col L

                Dim EsTemporal As Boolean
                EsTemporal = (InStr(1, TipoContrato, "Dur.temp", vbTextCompare) > 0 Or _
                              InStr(1, TipoContrato, "Duración determinada", vbTextCompare) > 0 Or _
                              InStr(1, TipoContrato, "Temporal.", vbTextCompare) > 0)

                Dim FechaHraw As Variant
                FechaHraw = wsOrigen.Cells(i, 8).Value2  ' col H numérico

                Dim EsGrupoA As Boolean
                If EsTemporal Then
                    If IsNumeric(FechaHraw) And FechaHraw > 0 And FechaHraw < H_SENTINEL Then
                        EsGrupoA = (DateDiff("d", FInicio, CDate(wsOrigen.Cells(i, 8).Value)) > 365)
                    Else
                        EsGrupoA = (DateDiff("d", FInicio, FRefFin) > 365)
                    End If
                Else
                    If IsEmpty(wsOrigen.Cells(i, 8).Value) Or FechaHraw = 0 Or FechaHraw = "" Then
                        EsGrupoA = True
                    ElseIf IsDate(wsOrigen.Cells(i, 8).Value) Then
                        EsGrupoA = (DateDiff("d", FInicio, CDate(wsOrigen.Cells(i, 8).Value)) > 365)
                    Else
                        EsGrupoA = True
                    End If
                End If

                ' ── Columna P — Unidades ──
                If EsGrupoA Then
                    wsOrigen.Cells(i, 15).Value = "Grupo A"
                    wsOrigen.Cells(i, 16).Value = Round(Dias / 365, 3)
                Else
                    wsOrigen.Cells(i, 15).Value = "Grupo B"
                    wsOrigen.Cells(i, 16).Value = Dias
                End If

                ' Memoria temporal
                DictBajas(NpersD) = FInicio - 1

            End If
        End If

    Next i

    ' ═══════════════════════════════════════════════════════
    ' FASE B: GENERACIÓN DE PESTAÑAS POR SOCIEDAD
    ' ═══════════════════════════════════════════════════════

    Set RangoA_S = wsOrigen.Range("A1:S" & UltimaFila)
    Set Diccionario = CreateObject("Scripting.Dictionary")

    For i = 2 To UltimaFila

        CodigoSoc = Trim(wsOrigen.Cells(i, 1).Text)

        If CodigoSoc <> "" And Not Diccionario.Exists(CodigoSoc) Then

            Diccionario.Add CodigoSoc, 1
            NombreHoja = Left(Replace(Replace(CodigoSoc, "/", "_"), "*", ""), 31)

            On Error Resume Next
            Sheets(NombreHoja).Delete
            On Error GoTo 0

            Set wsNueva = Sheets.Add(After:=Sheets(Sheets.Count))
            wsNueva.Name = NombreHoja

            wsOrigen.AutoFilterMode = False
            RangoA_S.AutoFilter Field:=1, Criteria1:=CodigoSoc

            RangoA_S.SpecialCells(xlCellTypeVisible).Copy Destination:=wsNueva.Range("A1")
            wsNueva.Columns.AutoFit

        End If

    Next i

    wsOrigen.AutoFilterMode = False

    ' ═══════════════════════════════════════════════════════
    ' FASE C: ORDENAR HOJAS NUMÉRICAMENTE
    ' ═══════════════════════════════════════════════════════

    Dim hojas() As Variant
    Dim idx As Long, j As Long, k As Long
    Dim temp As Variant

    ReDim hojas(1 To Diccionario.Count)
    idx = 1

    Dim key As Variant
    For Each key In Diccionario.Keys
        If IsNumeric(key) Then
            hojas(idx) = CDbl(key)
            idx = idx + 1
        End If
    Next key

    For j = LBound(hojas) To UBound(hojas) - 1
        For k = j + 1 To UBound(hojas)
            If hojas(j) > hojas(k) Then
                temp = hojas(j) : hojas(j) = hojas(k) : hojas(k) = temp
            End If
        Next k
    Next j

    For j = LBound(hojas) To UBound(hojas)
        If hojas(j) <> 0 Then
            On Error Resume Next
            Sheets(CStr(hojas(j))).Move After:=wsOrigen
            Set wsOrigen = Sheets(CStr(hojas(j)))
            On Error GoTo 0
        End If
    Next j

    Sheets(1).Activate

    Application.ScreenUpdating = True
    Application.DisplayAlerts  = True

    MsgBox "LGD v9 completado." & vbCrLf & _
           "Sociedades generadas: " & Diccionario.Count & vbCrLf & _
           "Las pestañas han sido ordenadas y pre-calculadas.", vbInformation

End Sub

🖥️ 3. Fase 2: Ejecución del Dashboard Web

3.1 El Archivo de Origen en la Web

El sistema web acepta el archivo global de SAP ya limpio. Buscará inteligentemente las columnas clave de tus Excels:

  • Empresa / Sociedad: Soc., BUKRS, Empresa, Sociedad ID.
  • Nombre de Empresa: Sociedad, Denominación, Nombre Empresa.
  • CCC (Centro de Trabajo): CCC Emp, CCC, Centro, C.C.C.
  • Nº Personal: Pernr, Nº pers, Numero de personal.
  • Fecha Inicial: Begda, Inicio, Alta, FeIniContr.
  • Fecha Final (Baja): Baja, Endda, Fin, Fecha de Baja.
  • Tipo de Contrato: CTTYP, Tipo Contrato, Modalidad, CC.
[!TIP]
Si subes el Excel con las múltiples pestañas generadas en la Fase 1, el Dashboard unificará la data de manera transparente.

3.2 Usando la Interfaz (Flujo de Carga Dual Opcional)

  1. Entra a la web "Calculadora Cuota Reserva 2%".
  2. (Opcional) Paso 1: Discapacitados. Arrastra a la zona delimitada tu Excel exclusivo de Personal con Discapacidad. El motor buscará inteligentemente columnas de nombre genérico como 'Sociedad', 'Fe.antig.', 'Baja' o 'CCC emp.' y almacenará automáticamente su vigencia sin preocuparse por la limpieza inicial del archivo o si sobran hojas.
  3. Paso 2: Datos SAP. Arrastra tu volcado maestro general .xlsx o .csv (de la Fase 1) a la zona principal (en azul).
  4. El motor procesará miles de filas cruzándolas en segundo plano con la memoria del archivo de discapacitados (si lo subiste), mostrando el panel KPI global automatizado al instante.
  5. Selector de Empresa: Navega entre empresas extraídas dinámicamente o usa el panel "Detalle Sociedad". El recálculo y la sincronización es 100% bidireccional si deseas modificar un valor manualmente en el "Modo Avanzado".

⚙️ 4. Lógica Matemática Web (Criterio 98/2016)

El Dashboard espeja fielmente la Ley:

  • 🟢 Grupo A: Contabiliza días vivos anuales divididos entre 365. Quien trabaja todo el año suma 1 entero.
  • 🟡 Grupo B: Haciendo click sobre esta tarjeta verás el desglose de trabajadores. Se suman sus días prestados temporalmente en el año, dividiéndolos entre 200 y redondeando, aplicando un cortafuegos para nunca exceder físicamente su número.

Suma Computable Legal: (Plantilla Grupo A) + (Plantilla Grupo B) = Base de obligación del 2%.

🏗️ 6. Arquitectura de Despliegue (Distribución de la Herramienta)

Para garantizar la distribución autónoma y segura del Dashboard Corporativo entre los usuarios sin pérdida de dependencias:

6.1 Despliegue Monolítico (Calculadora_LGD_Standalone.html)

Durante el circuito de desarrollo se mantiene el modelo de triple fichero (HTML / CSS / JS). Sin embargo, para la fase de cliente, hemos originado mediante PowerShell una variante denominada Calculadora_LGD_Standalone.html.

Este archivo extrae los binarios de style.css y script.js y los incrusta directamente en su propio <head>, conformando un ejecutable único.

  • Distribución: Enviar la herramienta implica mandar únicamente ese archivo. Almacenaje Zero-Config.

6.2 Embebido Cloud: Centro de Documentación (GitHub Pages)

El menú de Ayuda consta de 3 documentos visuales/legales. No se han incrustado en Base64 para no saturar el peso de la página web. En su lugar:

  • El proyecto se apoya en un hosting público permanente mediante GitHub Pages.
  • Los botones del popup están cableados interactivamente de manera hardcoded hacia Internet.
  • Se destruyeron los antiguos interceptores de Javascript locales del FileSystem dado que el enrutamiento converge ya 100% online.

🔒 7. Privacidad y Seguridad de Datos

Dada la sensibilidad de los datos de personal (NIF, Pernr, etc.), la herramienta ha sido diseñada bajo el principio de "Zero-Server Processing":

• Tratamiento 100% Local: Tus archivos Excel nunca suben a la nube ni a ningún servidor externo. El procesamiento ocurre exclusivamente en la memoria de tu navegador.
• Sin Base de Datos: Al cerrar la pestaña o refrescar (F5), los datos se borran por completo. Nada queda almacenado permanentemente fuera de tus archivos originales.
• Seguridad Estática: Al ser un archivo HTML autónomo, no tiene vulnerabilidades de backend ni requiere conexiones a bases de datos corporativas.

⌨️ 8. Atajos de Teclado y Tips de Uso

  • Cerrar Ventanas (ESC): Pulsa la tecla Escape en cualquier momento para cerrar los menús de ayuda, gestión de discapacitados o desgloses mensuales.
  • Navegación Fluida: Usa el selector de empresa para rotar entre resultados. Los datos de "Trabajadores Discapacidad" que introduzcas se mantendrán guardados para cada empresa mientras no cierres la herramienta.
  • Tooltips Informativos: Pasa el ratón sobre los iconos (i) en los KPIs para leer aclaraciones legales sobre qué se está sumando exactamente.
